🔗 Probabilidad Total

Usala cuando tienes varias fuentes posibles y quieres saber la probabilidad de que algo ocurra en total.

P(A) = P(fuente1)xP(evento|fuente1) + P(fuente2)xP(evento|fuente2) + ...
1
Identifica los grupos: maquinas, proveedores, medios de transporte...
2
Verifica que las proporciones sumen 1.00 (100%)
3
Multiplica la proporcion de cada grupo por su probabilidad interna
4
Suma todos los productos = probabilidad total

Ejemplo: Red publica 70% (1% bajones) + Solares 30% (4% bajones)

0.70 x 0.01 = 0.007\n0.30 x 0.04 = 0.012\nTotal = 0.007 + 0.012 = 0.019 = 1.9%
🔄 Teorema de Bayes

Bayes responde la pregunta al reves: ya se que paso algo malo (el chip es defectuoso), cual fue la causa mas probable?

P(causa | resultado) = [rama de esa causa] / [suma de todas las ramas]
1
Calcula la probabilidad total (denominador) con el metodo de arriba
2
El numerador es solo el producto de la causa que te preguntan
3
Divide: numerador / total

Ejemplo: Proveedor X 70% (2% defectos), Proveedor Y 30% (5% defectos). Si el chip es defectuoso, probabilidad de que sea de Y?

Total defectos: 0.70x0.02 + 0.30x0.05 = 0.014 + 0.015 = 0.029\nP(Y | defecto) = 0.015 / 0.029 = 0.517 = 51.7%

📊 Moda en datos agrupados (intervalos)

Cuando los datos vienen en rangos, usamos la formula de Czuber. Primero identifica la clase modal (el intervalo con mas frecuencia).

Mo = L + [(f - f-1) / ((f - f-1) + (f - f+1))] x A

📐 Mediana en datos agrupados

La mediana divide los datos en dos mitades iguales. Para datos agrupados:

Me = L + [(n/2 - F-1) / fi] x A
VariableQue esComo encontrarla
n/2La mitad del total de datosTotal de datos dividido entre 2. Ej: 80/2 = 40
LLimite inferior de la clase medianaEl numero izquierdo del intervalo donde cae n/2
F-1Frecuencia acumulada ANTERIORLa suma de frecuencias de todos los intervalos ANTES de la clase mediana
fiFrecuencia del intervalo medianaSolo la frecuencia propia de ese intervalo (no acumulada)
AAmplitudLimite superior menos limite inferior

Como encontrar la clase mediana: Calcula n/2, luego mira la columna Fi (acumulada) y busca el primer intervalo donde Fi sea mayor o igual a n/2.

Intervalo (kg)fiFi (acumulada)Nota

📈 Varianza y Desviacion Estandar

La varianza mide que tan separados estan los datos de su promedio. Datos muy juntos = varianza pequena. Datos muy dispersos = varianza grande.

Media (x) = suma de todos los valores / n\nVarianza (o2) = suma de (xi - x)^2 / N\nDesv. Estandar (o) = raiz cuadrada de o2\nCV = (o / x) x 100%

Ejemplo paso a paso: datos 12, 15, 10, 18, 14

xixi - media(xi - media)^2
1212-14 = -24
1515-14 = 11
1010-14 = -416
1818-14 = 416
1414-14 = 00
Suma=69, media=14-Suma=37
o2 = 37/5 = 7.4 o = raiz(7.4) = 2.72 CV = (2.72/14)x100 = 19.4%

CV bajo (menos de 10%) = datos muy homogeneos. CV alto (mas de 30%) = mucha dispersion.

🎯 Distribucion Binomial

Usala cuando: tienes n intentos, cada intento tiene solo exito o fracaso, y la probabilidad p es igual en cada intento.

P(X = k) = C(n,k) x p^k x (1-p)^(n-k)
SimboloNombreComo identificarlo en el problema
nNumero de intentos"Se hacen 10 envios" = n=10
kExitos que nos piden"exactamente 9 exitosos" = k=9
pProbabilidad de exito"92% son exitosos" = p=0.92
1-pProbabilidad de fracaso1 - 0.92 = 0.08
C(n,k)Combinacionesn! / (k! x (n-k)!)
Media esperada: mu = n x p
